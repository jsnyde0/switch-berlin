## Scope

**In:**
- **Admin-reviewed open signup form** replaces pure invite. Anyone can fill `/accounts/signup/`; account lands in `is_approved=False` state; admin reviews daily; approved accounts can write (attend, follow, rate, flag).
- **Organizer self-serve edits** — approved organizers can edit their own upcoming events and profile. Edits to published events auto-revert to `status='review'` if they change: price, date, venue. Other edits (description, typo fix) publish immediately. Audit log: `OrganizerEdit` table.
- **Bubble-bridging UI** — filter chips expose bubbles (`Tag.kind='bubble'`) prominently; "people who follow X also attend Y" cross-bubble surfacing.
- **Observability** — Logfire dashboards for extraction success rate, admin review backlog, flag volume, signup approval time.
- **Rate limiting** — django-ratelimit or similar on write endpoints; anti-brigading rate limits on flag submission.
- **Panic mode kill-switch** — one admin toggle `PUBLIC_SIGNUPS_OPEN=False` reverts to invite-only (ADR-003 F9, ADR-002 discusses explicitly).
- **Week-off runbook** — documented `docs/runbooks/week-off.md` listing what can break while maintainer is unreachable, what auto-heals, what to flip off before leaving.

**Out:**
- Ticketing / payments — V4+ per ADR-001, explicitly out.
- Multi-city — post-12-month per ADR-001 D2.
- Mobile apps — out.
- Messaging/DMs — banned per ADR-002 D4.
- Embeddings / recommendations — post-1.0.

## Data model deltas

### `accounts.SignupApplication`
```python
class SignupApplication(models.Model):
    user = OneToOneField(User, on_delete=CASCADE, related_name="application")
    submitted_at = DateTimeField(auto_now_add=True)
    motivation = TextField(blank=True)  # optional: why do you want to join?
    referrer = CharField(max_length=200, blank=True)  # how did you hear about us?
    status = CharField(choices=[("pending","Pending"),("approved","Approved"),("rejected","Rejected")], default="pending")
    reviewed_by = FK(User, null=True, blank=True, on_delete=SET_NULL, related_name="applications_reviewed")
    reviewed_at = DateTimeField(null=True, blank=True)
    reviewer_notes = TextField(blank=True)
```

### `organizers.OrganizerEdit`
```python
class OrganizerEdit(models.Model):
    organizer = FK(Organizer, on_delete=CASCADE, related_name="edit_log")
    editor = FK(User, on_delete=PROTECT)
    event = FK(Event, null=True, blank=True, on_delete=SET_NULL)  # null if organizer-profile edit
    field_changed = CharField(max_length=100)
    old_value = TextField(blank=True)
    new_value = TextField(blank=True)
    triggered_review = BooleanField(default=False)  # did this edit flip Event.status to 'review'?
    created_at = DateTimeField(auto_now_add=True)
```

### `accounts.OrganizerUserLink`
```python
# Connects a User to the Organizer they can edit
class OrganizerUserLink(models.Model):
    user = FK(User, on_delete=CASCADE, related_name="organizer_links")
    organizer = FK(Organizer, on_delete=CASCADE, related_name="user_links")
    role = CharField(choices=[("owner","Owner"),("editor","Editor")], default="editor")
    created_at = DateTimeField(auto_now_add=True)
    created_by = FK(User, on_delete=PROTECT, related_name="organizer_links_granted")

    class Meta:
        unique_together = [("user","organizer")]
```

Approved by admin one-by-one; solo maintainer workload scales linearly with organizer count — acceptable since that's bounded (~50 approved organizers at 1.0).

## UI deltas

- `/accounts/signup/` — open form (no `?code=` required).
- `/me/application-status` — for users whose account is pending approval.
- `/o/<slug>/edit` — route restricted to users with `OrganizerUserLink` for that organizer.
- `/events/<slug>/edit` — same.
- Admin dashboard: "Today's signups to review" widget; "Organizer edits pending re-review" widget.
- Public landing `/` — polish pass (hero, social proof: "N events this week from M organizers", footer links).

## Rate limiting

- Flag submission: 5/hour/user, 20/day/user.
- Review submission: 10/day/user.
- Signup attempts: 3/hour/IP.
- Takedown form: 10/hour/IP, CAPTCHA after 3.

## Observability

Logfire dashboards:
- Extraction success rate per day (target >80%).
- Admin review backlog (draft events older than X hours).
- Signup approval backlog (pending applications older than 48h = SLA breach).
- Flag volume per day, resolution time distribution.
- Page-view counts per route (aggregate, no personal data).

## Week-off runbook (`docs/runbooks/week-off.md`)

- Flip `PUBLIC_SIGNUPS_OPEN=False` 1–2 days before leaving.
- Check `RawMessage.extraction_status='failed'` count before leaving; resolve or document as known.
- Set out-of-office on takedown email; note 72h SLA may extend.
- Monitor Logfire alerts via phone.
- On return: review signup queue, flag queue, organizer-edit queue in that order.

## Test plan

- Open signup flow: signup → pending → admin approve → can write.
- Organizer self-edit: as owner, edit own event description (no review trigger); edit own event price (triggers review); verify `OrganizerEdit` row + `Event.status='review'`.
- Rate limits: 6th flag in an hour → 429.
- Panic mode: flip `PUBLIC_SIGNUPS_OPEN=False` → signup form returns 503 with "temporarily closed" message.
- Logfire export: assert dashboards populated with real data (smoke test).

## Go/no-go (launch success criteria)

- **200 WAU within 6 weeks post-launch.**
- **≤15 min/day admin load sustained** across 8 consecutive weeks.
- **≥6 active organizers** (posted ≥1 event in trailing 30 days).
- **No legal complaint** through launch + 6 weeks.
- **No brigading or abuse incident** that required emergency action.

## Rollback / panic path

- `PUBLIC_SIGNUPS_OPEN=False` → invite-only (back to 0.4 posture for writes).
- `PUBLIC_READ_ENABLED=False` → login-wall re-enabled everywhere.
- `ORGANIZER_SELF_EDIT=False` → edit routes 503.
- `INGESTION_PAUSED=True` → bot stops processing forwards.
- All of the above available as one-click `FeatureFlag` toggles. Combined: "full panic mode" restores the 0.4 posture in <60 seconds.
