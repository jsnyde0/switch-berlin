# Phase 0.1 — Schema + admin + manual entry

**Date:** 2026-04-17
**Status:** Draft (target: phase start)
**Parent roadmap:** [§0.1](2026-04-17-roadmap-0.1-to-1.0.md#01--schema--admin--manual-entry-private)
**ADRs:** [ADR-001 D8](../decisions/ADR-001-core-product-and-stack.md), [ADR-003 F1–F7](../decisions/ADR-003-cheap-foresight-patterns.md)
**Target state:** [1.0 design](2026-04-17-v0-design.md)
**Audience:** maintainer only. No auth, no public surface, no ingestion.
**Risk killed:** schema can't represent real Berlin events.

## Scope

**In:**
- Django apps: `organizers`, `venues`, `events`, `ingestion`, `reviews`.
- Normalized schema per ADR-001 D8 with ADR-003 foresight patterns F1–F7 baked in.
- `CREATE EXTENSION vector` via migration (F1 — extension on, no `VectorField` yet).
- Django admin customizations: list displays, search fields, list filters, inline raw↔parsed on `Event`, bulk actions (approve, reject, merge-duplicates stub).
- Approval flag on `User` (`is_approved: bool`) + middleware placeholder (not wired to any route yet — just the field exists).
- `{% trans %}` wrappers on every user-facing string from day 1 (F6).
- `django-q2` wired to Postgres broker, one dummy scheduled task to prove it runs.
- CI: ruff, djlint, pytest smoke test per model.

**Out:**
- Ingestion (Telegram bot, URL enrichment, LLM extraction) — phase 0.2.
- Public templates, HTMX surface, React island — phase 0.3+.
- Auth/allauth wiring beyond the User field — phase 0.3+.
- Any kill-switch infrastructure (F9) — added per-feature as those features ship.

## Data model

### `organizers.Organizer`
```python
class Organizer(models.Model):
    # Identity
    name = CharField(max_length=200)
    slug = SlugField(unique=True)
    description = TextField(blank=True)
    avatar = ImageField(upload_to="organizers/", blank=True, null=True)
    website = URLField(blank=True)
    telegram_channel = CharField(max_length=200, blank=True)

    # Trust tier
    status = CharField(choices=[("candidate","Candidate"),("approved","Approved"),("suspended","Suspended")], default="candidate")
    verified_badge = BooleanField(default=False)
    approved_at = DateTimeField(null=True, blank=True)
    approved_by = FK(User, null=True, blank=True, on_delete=SET_NULL)

    # GDPR consent (F5 — captured from 0.2, consumed from 0.5)
    consent_recorded_at = DateTimeField(null=True, blank=True)
    consent_method = CharField(
        choices=[
            ("telegram_forward_implied","Telegram forward (implied)"),
            ("explicit_opt_in","Explicit opt-in"),
            ("verified_public_source","Verified public source"),
        ],
        blank=True,
    )
    consent_notes = TextField(blank=True)

    # Timestamps
    created_at = DateTimeField(auto_now_add=True)
    updated_at = DateTimeField(auto_now=True)
```

### `events.Event`
```python
class Event(models.Model):
    title = CharField(max_length=300)
    slug = SlugField(unique=True)
    description = TextField(blank=True)
    organizer = FK(Organizer, on_delete=PROTECT, related_name="events")
    venue = FK(Venue, on_delete=PROTECT, null=True, blank=True, related_name="events")
    tags = M2M(Tag, blank=True, related_name="events")

    # Time
    start = DateTimeField()
    end = DateTimeField(null=True, blank=True)
    timezone = CharField(max_length=50, default="Europe/Berlin")

    # Price
    price_min_cents = IntegerField(null=True, blank=True)
    price_max_cents = IntegerField(null=True, blank=True)
    currency = CharField(max_length=3, default="EUR")
    is_free = BooleanField(default=False)
    sliding_scale = BooleanField(default=False)

    # External
    external_url = URLField(blank=True)
    tickets_url = URLField(blank=True)

    # Lifecycle
    status = CharField(
        choices=[("draft","Draft"),("review","Needs review"),("published","Published"),("rejected","Rejected"),("archived","Archived")],
        default="draft",
    )
    published_at = DateTimeField(null=True, blank=True)

    # Provenance (F7)
    raw_message = FK("ingestion.RawMessage", null=True, blank=True, on_delete=SET_NULL)

    # Cheap foresight: NO VectorField (F1). Add via additive migration when needed.

    created_at = DateTimeField(auto_now_add=True)
    updated_at = DateTimeField(auto_now=True)

    class Meta:
        indexes = [Index(fields=["status","start"]), Index(fields=["organizer","start"])]
```

### `reviews.Review` (F2)
```python
class Review(models.Model):
    author = FK(User, on_delete=CASCADE, related_name="reviews")
    organizer = FK(Organizer, null=True, blank=True, on_delete=CASCADE, related_name="reviews")
    event = FK(Event, null=True, blank=True, on_delete=CASCADE, related_name="reviews")
    rating = IntegerField(validators=[MinValueValidator(1), MaxValueValidator(5)])
    body = TextField(blank=True)
    created_at = DateTimeField(auto_now_add=True)

    class Meta:
        constraints = [
            CheckConstraint(
                check=Q(organizer__isnull=False) ^ Q(event__isnull=False),
                name="review_targets_exactly_one",
            ),
        ]
```

## Admin customizations

- **OrganizerAdmin:** list_display (name, status, verified_badge, event_count), list_filter (status, verified_badge), search_fields (name, slug, telegram_channel), readonly on timestamps. Bulk action: "Mark approved + record consent".
- **EventAdmin:** list_display (title, organizer, start, status), list_filter (status, start, tags, organizer), search_fields (title, description), inline `EventImage`, side-panel showing linked `RawMessage.text` and `enriched_payload`. Bulk actions: publish, reject, archive.
- **RawMessageAdmin:** list_display (source_type, received_at, extraction_status, short text preview), filter by extraction_status. Read-only in 0.1 (no actions until 0.2 extraction pipeline).
- **ReviewAdmin:** list_display (author, target_display, rating, created_at), target_display computed from organizer XOR event.

## UI/API surface

- No DRF endpoints.

## Test plan

- `pytest` smoke tests: every model round-trips create/read.
- `Review` constraint: saving with both `organizer` and `event` set raises IntegrityError; saving with neither raises too.
- `Event.status` transitions: draft → review → published → archived allowed; archived → draft not enforced at DB level (documented as admin convention).
- Admin smoke test: `GET /thebaws/` returns 200 after superuser login.
- `django-q2` dummy task: scheduled to run every minute, logs timestamp to prove worker loop is alive.
- CI: ruff (python), djlint (templates), pytest — all green before merge.

## Go/no-go to 0.2

- Maintainer hand-enters ≥30 real Berlin events spanning ≥8 organizers.
- Zero fields feel like workarounds (document any workaround; if >1, this phase is not done).
- Admin review workflow (approve/publish) takes <30 seconds per event.
- `django-q2` has run ≥24 hours without a crash.

## Rollback

Phase is purely additive (new tables). Rollback = migrate backward to zero + drop the new apps from `INSTALLED_APPS`. No public traffic yet, no user data to preserve.
