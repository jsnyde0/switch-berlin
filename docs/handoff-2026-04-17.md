## Key non-obvious things about the stack

- **No Redis.** django-q2 uses the Postgres ORM broker. One less container.
- **Session auth + `json_script` + CSRF cookie** handles Django → React handoff. No JWT, no CORS, no Inertia.
- **DaisyUI across both surfaces** — don't add shadcn, it collides with DaisyUI CSS variables.
- **Tailwind v4 is the new pipeline** — single `frontend/src/app.css` with `@import "tailwindcss"; @plugin "daisyui"` and `@source` globs covering both Django templates and React island.
- **`pgvector/pgvector:pg17`** image — enable extension in first migration (F1), but no VectorField columns until a feature needs them.
- **Allauth 65.x uses `ACCOUNT_LOGIN_METHODS` / `ACCOUNT_SIGNUP_FIELDS`** — already updated.
- **macOS lacks `timeout` binary** — the bd pre-commit hook deadlocks if a prior `bd init`/`bd export` process is still running. `ps aux | grep bd` if a commit hangs.
