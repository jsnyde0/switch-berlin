{% comment %} Editorial form field — mono caps label, hairline-bottom input. Attributes: label — mono caps label text name — form field name type — input type (default "text") value — current value placeholder required (any truthy) autocomplete hint — small mono note under the field errors — list-like of error strings (e.g. form.email.errors) id — explicit field id (else "field-{name}") inputmode For non-input fields (textarea, select), use `c-kb.field-wrap` and place custom markup in the slot. {% endcomment %}
